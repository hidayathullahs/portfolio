# Contributing to Hidayathullah's Portfolio

Thank you for your interest in contributing! Whether you are reporting a bug, suggesting an aesthetic improvement, or proposing a new project highlight, your input is welcome.

---

## 🛠️ Development Guidelines

### 1. Branch Strategy
- `main` is the primary production branch.
- Feature branches should follow standard naming conventions:
  - `feature/your-feature-name`
  - `fix/your-bugfix-name`
  - `docs/your-doc-update`

### 2. Commit Message Standards
We follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` New features or UI components
- `fix:` Bug fixes or alignment corrections
- `docs:` Documentation updates
- `style:` Formatting or aesthetic adjustments
- `refactor:` Code reorganization without functionality changes
- `chore:` Dependency maintenance or configuration

### 3. Local Verification
Before submitting changes, ensure the build passes cleanly:

```bash
npm run build
```
