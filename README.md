A modern, high-performance developer portfolio built with **React**, **Vite**, and **Tailwind CSS**. Designed with an editorial, magazine-inspired aesthetic featuring a signature golden-orange sun backdrop, hand-drawn annotations, dark ribbon skill showcase, and direct contact integration via FormSubmit.

---

## 🌟 Key Highlights & Features

- **🎨 Editorial Hero Design**: Warm `#FF6A00` sun backdrop with concentric geometry, hand-drawn doodle rays, and 3D floating credibility badges.
- **⚡ Enterprise Project Showcases**:
  - **Life Flow**: Smart blood donor search platform with real-time Firebase sync.
  - **TaskFlow Enterprise**: Project management platform built with Spring Boot 3, Java 21, React, and WebSockets.
  - **DressChanger AI**: Computer vision try-on prototype using MediaPipe and OpenCV body landmark anchoring.
  - **Smart Money**: Offline-first personal finance app built with Flutter and SQLite.
  - **Azeem AI**: Multilingual AI tutor supporting regional Indian languages.
  - **Ultimate Jarvis**: Voice-first AI desktop assistant with neural speech feedback.
- **📬 Functional Contact System**: Real-time form submissions powered by FormSubmit with instant delivery to `hidayathullahbajar@gmail.com` and one-click email client fallback.
- **📱 Fully Responsive**: Pixel-perfect layout across mobile, tablet, laptop, and ultra-wide displays.
- **✨ Micro-Interactions**: Confetti celebration triggers, glassmorphic floating pills, and smooth section navigation.

## 💻 Local Development Setup

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/hidayathullahs/portfolio.git

# 2. Navigate into the directory
cd portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the portfolio locally.

### Production Build

```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
