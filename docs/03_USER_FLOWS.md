# 03 — User Flows

```text
Visitor Lands on Portfolio
       ↓
[Hero Section]
  ├── Clicks "View My Work ↗" ──→ Smoothly scrolls to Projects Section
  ├── Clicks "Download Resume"  ──→ Downloads / Opens /resume.pdf
  └── Reads Left Text, Profile & 4 Info Cards
       ↓
[Services Section] ──→ Discovers Web, Web Apps, Mobile, AI, Backend & UI/UX services
       ↓
[About Section]    ──→ Reads authentic background and 2022–Present timeline
       ↓
[Skills Section]   ──→ Scans technical skills organized across 8 categories
       ↓
[Projects Section]
  ├── Clicks Filter (Web, Mobile, AI, Enterprise, Game) ──→ Filters project cards
  ├── Clicks "Live Demo" ──→ Opens live deployed application
  ├── Clicks "GitHub"    ──→ Opens repository on GitHub
  └── Clicks Project Card / "Case Study" ──→ Opens Project Detail Modal
       ↓
[Certifications]   ──→ Inspects verified credentials & opens credential links
       ↓
[Resume Section]   ──→ Downloads full resume PDF
       ↓
[Contact Section]  ──→ Submits message via form / Connects via LinkedIn & GitHub
```
